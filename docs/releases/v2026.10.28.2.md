# Craft Portal v2026.10.28.2

Administrators can remove apps for all users, including their installed app
code, and restore their original repository configuration later. Removal revokes
app sessions and pending launch tickets and prevents automatic rediscovery.
Browser documents are not deleted. The existing personal dock configuration
continues to let each user select visible app icons independently.

This release also includes the compatible GitHub app registration feature from
v2026.10.28.1. Update the existing Unraid container using
`ghcr.io/timminater/craft-portal:latest` and retain your data volume and origins.
