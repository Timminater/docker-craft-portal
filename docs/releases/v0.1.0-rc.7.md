# Docker Craft Portal v0.1.0-rc.7

Each known Craft app card now names its inspiration, for example "Inspired by
Adobe Photoshop", "Adobe Illustrator" or "Microsoft Word". The label follows
the portal's English/Dutch language selection. References match each app's
official README; SoundCraft references Avid Pro Tools.

Searching includes these product names, so Photoshop finds PhotoCraft,
Illustrator finds VectorCraft and Word finds WordCraft. Matching ignores case
and surrounding whitespace. Initial rendering, live typing and subsequent
navigation/polling use the same filtering function, preserving favorite ordering
and disabled-app handling. Newly discovered apps without a verified reference
retain their normal card without an invented comparison.

89 regular tests pass. Browser review in English and Dutch checks visible labels,
Photoshop/Illustrator/Word/Pro Tools/Excel searches, navigation with a search
active, clearing the search, mobile overflow and console errors. Mandatory
Chromium/Firefox and AMD64/ARM64 checks gate image publication.

Update the existing container using `latest` and reload the portal. No settings
or data migration is needed.
