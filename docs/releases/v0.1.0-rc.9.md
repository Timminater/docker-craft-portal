# Craft Portal v0.1.0-rc.9

Adds SolidCraft from the explicitly authorized `bherbruck/solidcraft` repository.
The self-hosted WASM app appears in the library and dock with official artwork,
a searchable Autodesk Fusion reference, native download links and the existing
update/rollback/personal-order controls. Default startup discovery installs it;
Administration → Check now also triggers discovery.

Publisher trust is extended only to this exact repository. SHA-256 verification,
ZIP limits, atomic installation and original ArtCraft publisher checks remain.
The upstream offline service-worker registration is removed before activation,
with unknown registration changes failing closed to preserve the installed release.
Ordinary workers and app authorization remain available.

The real v0.12.0 release passed download/checksum/install and Chromium browser
acceptance, both embedded and separately, including rendering a sample 3D model.
No console/network errors occurred in the adapted app. 115 regular tests pass;
mandatory hosted Chromium/Firefox and AMD64/ARM64 checks gate image publication.
See [SolidCraft details and evidence](../solidcraft.md).

Update `latest` and reload the portal. No new container settings or migration are
needed. Keep automatic discovery enabled to add the new app.
