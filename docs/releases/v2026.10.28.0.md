# Craft Portal v2026.10.28.0

Administrators can review and set the GitHub owner and repository used for each
installed application under Administration. A source change is an explicit
trust decision: its code runs in users' browsers. Existing stable-tag, asset
name, SHA-256, size and archive checks remain in effect. Existing versions and
browser documents are retained; a different source with an identical version
tag does not replace an already installed version.

SolidCraft's default source follows the GitHub transfer from bherbruck to
tangency-labs. Its changed offline registration is adapted without removing
the adjacent application startup code. Version 0.13.1 and the current upstream
v0.25.1 were downloaded, verified and activated in an isolated local portal.
The upstream release available during a future update may differ.

Update the existing Unraid container from `ghcr.io/timminater/craft-portal:latest`
and retain the existing data volume and domain configuration. After restarting,
use Administration → Check now to check the application releases.
