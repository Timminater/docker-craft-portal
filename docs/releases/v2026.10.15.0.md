# Craft Portal v2026.10.15.0

First stable, calendar-versioned Craft Portal release. The project and GitHub
repository use Craft Portal / `craft-portal`; the Docker image and Unraid template
use the same name. This release is published without the prerelease flag and is
marked as the latest GitHub release.

Includes the compact application library, Dutch/English localization, official
app artwork, searchable app inspirations, embedded app workspace, centered dock
with hover magnification, personal per-account app ordering, shared app-host
multi-user mode and self-hosted SolidCraft. Existing authentication, checksum-
verified updates, rollback, retained versions and database backups remain available.

## Update

Canonical image: `ghcr.io/timminater/craft-portal:latest`, or pin
`ghcr.io/timminater/craft-portal:v2026.10.15.0`.
The previous `ghcr.io/timminater/docker-craft-portal` image is also published as a
compatibility alias, so existing containers can receive this update. In Unraid,
change Repository to the canonical image and optionally rename the container to
`craft-portal`. Keep the same appdata mapping, accounts and origin settings.
No document, account or storage migration is required. Reload the portal.

The installable user template is `unraid/craft-portal.xml`. Old GitHub links
redirect after the repository rename; use the new project URLs going forward.

## Validation

115 regular tests pass locally. The release workflow gates publication on the
Chromium/Firefox browser suite and AMD64/ARM64 container builds. Real PhotoCraft
and SolidCraft web releases were verified, including actual SolidCraft 3D sample
rendering. See acceptance evidence and known limitations for the tested scope;
other app-specific features and native ARM64 runtime remain separately tracked.
