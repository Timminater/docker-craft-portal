# Docker Craft Portal v0.1.0-rc.6

The toolbar above embedded apps now uses a compact single-row layout. Smaller
controls and title truncation leave more space for the editor. Mobile controls
use icons with accessible labels and tooltips. Launch/error feedback remains
available. The bottom dock retains its 52 px height and official artwork.

Includes the official icon/hero cache and offline icon bundle introduced in rc.5.
The operator confirmed the separate app hostname's TLS issue is resolved and
apps now appear. This is operator feedback; the managed cloud proxy still blocks
our direct live-browser visit. Real PhotoCraft v0.9.0 starts correctly embedded
and separately in the local HTTPS acceptance environment.

The existing browser suite, unit tests and AMD64/ARM64 build gate publication.
`latest` advances to this verified image. Keep existing appdata and configuration;
reload the portal after recreating the container.
