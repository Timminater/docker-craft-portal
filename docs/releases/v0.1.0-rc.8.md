# Docker Craft Portal v0.1.0-rc.8

Every account can now save a personal app order. Choose **Arrange applications**
beside the library search, drag rows or use the up/down buttons, and save.
The order applies to cards and dock, survives restarts, and loads on other devices.
Search preserves relative order. Newly discovered apps append alphabetically;
Default order restores favorite-first sorting. Closing without saving cancels.
Reordering preserves open app frames and their unsaved state.

Preferences are stored against the authenticated account in an additive SQLite
table. Other users' orders remain independent. Writes require CSRF validation
and accept only bounded, unique known app identifiers. Existing appdata and
settings remain valid; the database backup includes preferences.

Dock icons now magnify to 1.65× on pointer hover, with 1.22× neighboring icons.
Transparent space above the unchanged 52 px bar prevents clipping; app controls
above the dock remain clickable. Reduced-motion preferences disable scaling.

101 regular tests pass locally. English/Dutch browser acceptance exercises save,
reload, accounts, cancel/reset, mobile keyboard control, search/favorites and
retained iframe state. Independent review found no concrete blockers. Mandatory
hosted Chromium/Firefox and AMD64/ARM64 checks gate `latest` publication.

Update the container and reload the portal. No new environment settings needed.
