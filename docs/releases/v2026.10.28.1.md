# Craft Portal v2026.10.28.1

Administrators can add compatible Craft web applications from an exact GitHub
repository in Administration, without modifying or rebuilding the portal.
New apps use the same release metadata, SHA-256, archive bounds and session
authorization checks as existing applications. An update check is scheduled
after registration when possible. App code runs in users' browsers: trust the
publisher you select. See [the source setup guide](../solidcraft.md).

Update the existing Unraid container from `ghcr.io/timminater/craft-portal:latest`
and retain its existing data volume and origin settings.
