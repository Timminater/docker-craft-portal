# Craft Portal v0.1.0-rc.5

The bottom dock is now 52 px high, with centered official Craft app icons and a
subtle pointer-hover zoom. Keyboard labels, mobile overflow and reduced-motion
preferences remain supported. The sidebar logout action stays above the dock.

Cards use the official `hero.webp` and dock icons use `icon.webp` from
getartcraft.com's app image paths. The server caches them locally with bounded
HTTPS downloads, no GitHub credentials and no direct browser requests to the
external site. Official icons are also bundled for offline use with source and
license attribution. Missing artwork has a local fallback.

89 regular tests pass locally. Existing Chromium workspace and portal acceptance
runs cover the new image routes without console failures; mandatory hosted
Chromium/Firefox and AMD64/ARM64 checks gate package publication.
A real official PhotoCraft v0.9.0 ZIP was checksum-verified and the full editor
rendered both embedded and separately on local HTTPS. Its missing optional font
manifest gives a non-blocking upstream 404; other genuine apps remain unverified.

The operator reported `SSL_ERROR_UNRECOGNIZED_NAME_ALERT`. This is a TLS/SNI
configuration failure before HTTP, not an app-loading error fixed by this image.
Configure the fixed app hostname in DNS and the reverse proxy with an ordinary
certificate, and clear wildcard mode when not using wildcard TLS. See
[workspace troubleshooting](../workspace.md#tls-errors-when-opening-an-app).
The live portal remains unreachable from the cloud proxy, so no live login or
successful live app launch is claimed.

`latest` is updated after successful release verification. Keep existing appdata
and origins. No migration is needed for the appearance changes.
