# Craft Portal v2026.10.15.1

Adds personal account settings, browser storage information, configurable dock
visibility and a portal/application update overview in Dutch and English.

- Change your own password and revoke other devices' portal/app sessions.
- Enable optional authenticator-based two-step verification, with ten one-time
  recovery codes. Save the recovery codes before closing enrollment.
- Inspect approximate usage/quota and request persistent browser storage on the
  actual application origin. Shared-host applications appear as one group.
  Browser projects still need to be exported from their editors; server backups
  do not include them.
- Select which apps appear in your personal dock. Existing custom ordering is
  preserved, and hidden running apps remain visible until closed.
- See the running portal version, explicitly check the latest stable release
  as administrator, and follow application download/extraction/activation progress.
  Portal updates continue through Docker/Unraid.

## Update

Pull `ghcr.io/timminater/craft-portal:latest`, or pin
`ghcr.io/timminater/craft-portal:v2026.10.15.1`, and recreate the container with
the existing `/data` mapping and origin settings. The previous
`ghcr.io/timminater/docker-craft-portal:latest` image remains a compatibility alias.
Reload the portal after updating.

The SQLite upgrade is additive and retains accounts, sessions and app order.
Old sessions receive safe display identifiers and unknown browser labels.
Protect `/data` and its backups: activated authenticator secrets live in the
database. Offline restore retains activated factors and unused recovery hashes
while revoking sessions, tickets and unfinished enrollments.

See [personal settings](../personal-settings.md) for exact behavior and browser
limitations. Browser storage persistence is controlled by the browser and is
not a backup or document synchronization feature.

## Validation

Publication is gated by the Python suite, strict Chromium/Firefox browser
acceptance and AMD64/ARM64 image builds with a hardened nonroot runtime smoke
check. The new account tests cover session ownership, factor replay/recovery,
concurrent credential changes and migration from the previous schema. Real
SolidCraft v0.12.0 was downloaded, checksum verified and activated through the
unchanged trusted release installation path.
