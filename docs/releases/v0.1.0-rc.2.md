# Docker Craft Portal v0.1.0-rc.2

## Library and visual polish

- Replaced the large introductory banner with a compact library toolbar.
- Added local category illustrations, stable app colors and concise descriptions.
- Fixed blocked inline styling while preserving the strict Content Security Policy.
- Added a local favicon and SVG launch indicators; no external artwork requests.

## English and Dutch

Onboarding and the portal now follow the browser's preferred supported language.
Dutch language variants select Dutch; English variants select English; unsupported
languages fall back to English. This includes navigation, setup/login, admin,
users, activity, dialogs, known errors and the app-session bridge, with localized
dates, numbers and plurals. No account migration or language environment variable
is required. Reload after changing browser language preferences. Language inside
upstream ArtCraft apps remains controlled by each app.

## Validation and upgrade

Local checks: 65 non-browser tests passed, seven Chromium workflows passed, and
the translation-module test passed. Clean-console workflows checked every portal
page in Dutch, English and unsupported-language fallback. Existing WASM,
rollback and OPFS isolation tests remain passing. The hardened native image was
built and started with nonroot access to the shared translation module and CSS.
Hosted strict browser and multiarchitecture CI gates this package publication.

The operator's live URL was blocked by the development environment proxy, so the
visual/console review used the same portal source locally with synthetic data.
No production credentials were stored or used in test artifacts. Real upstream
ArtCraft compatibility remains a separate pre-production acceptance gate.

In Unraid, change the container Repository tag to `v0.1.0-rc.2`, pull/recreate the
container and keep the existing appdata mapping and origin settings. Accounts,
installed app versions and settings are retained. Reload the browser afterward.
The repository Unraid user template is updated to this version. Use the explicit
version tag; this release does not move the existing `latest` alias from rc.1.

See docs/UI_REVIEW.md for visual evidence and docs/i18n.md for language behavior.
